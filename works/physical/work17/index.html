06제작 이야기

🗓 8차시의 기록

  1. 문제 선정과 계획서 작성 (1차시)
  2. 코딩 틀 잡기, 클래스별 40~50장 학습 (2차시)
  3. UI 디자이너와 코드 작성 (3차시)
  4. AI 재학습과 판별 코드 보완 (4~5차시)
  5. 테스트와 자료 정리, 발표 대본 (6~8차시)
