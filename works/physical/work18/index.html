🍽️ 급식판 검사기

급식판을 카메라에 비추면 AI가 잔반이 있는지 검사해, 다 비웠으면 상점과 신나는 노래를, 남겼으면 벌점을 주는 잔반 줄이기 시스템입니다.

01왜 만들었나요?

🍚

문제 발견

급식 잔반이 많아지면 처리 비용이 늘어나고, 그만큼 급식의 질이 떨어져요.

💡

해결 아이디어

급식판을 카메라로 검사해서 다 비우면 상점, 남기면 벌점을 주자!
상점을 받으려고 잔반을 남기지 않게 될 거예요.

🌱

기대 효과

잔반이 줄면 처리 비용이 감소하고, 아낀 비용만큼 급식의 질이 좋아집니다.

04핵심 코드

AI이거다 블록 코딩으로 작성한 실제 프로그램을 그대로 옮긴 것입니다.
스페이스바 한 번으로 검사가 실행되고, 결과에 따라 상점·벌점이 쌓이며 마이크로비트가 표정과 노래로 반응합니다.

메인 프로그램 — 급식판 검사와 상벌점

🚩 프로그램이 실행될 때 변수 상점 = 0, 변수 벌점 = 0 계속 반복하기 상점·벌점 텍스트를 변수 값으로 갱신하기 ⌨️ 키보드의 Space 키가 눌렸을 때 AI 모델의 분류 결과 요청하기 만약 분류 결과가 클래스 잔반없음 인가? 라면 상점 +1 + 화면에 Yes + 소리 HAPPY 재생 아니면 (잔반이 있다면) 벌점 +1 + 화면에 No + 소리 SAD 재생
