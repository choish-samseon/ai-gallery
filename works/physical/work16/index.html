🏀 AI 농구 점수판

라인 밖 슛은 3점, 안쪽 슛은 2점!
카메라가 슛 위치를 인식하고 버튼 하나로 점수가 자동 합산되는, 경기 흐름을 끊지 않는 자동 점수판입니다.

01왜 만들었나요?

🏀

문제 발견

학교 농구 대회에서 다 같이 경기를 보고 싶은데, 점수와 시간을 조정하느라 경기를 잠깐씩 놓치게 돼요.

💡

해결 아이디어

라인 밖에서 쏘면 3점, 안에서 쏘면 2점 — 슛 위치를 카메라가 인식해 점수를 자동으로 올려주자!

🌱

기대 효과

진행자가 수동으로 점수를 올릴 필요가 없어, 경기 흐름이 끊기지 않고 모두가 경기에 집중할 수 있습니다.

04핵심 코드

AI이거다 블록 코딩으로 작성한 실제 프로그램을 그대로 옮긴 것입니다.
A 버튼으로 슛 위치를 판정해 두고, 골이 들어가면 B 버튼 한 번으로 점수가 자동 합산되어 마이크로비트 화면에 흐릅니다.

메인 프로그램 — 슛 판정과 점수 누적

🔘 A 버튼이 눌린 적이 있는가? 일 때 (슛 위치 판정) 점수 확인 모델의 분류 결과 요청하기 만약 분류 결과가 클래스 3점 인가? 라면 변수 슛의 값을 3으로 정하기 혹은 분류 결과가 클래스 2점 인가? 라면 변수 슛의 값을 2로 정하기 🔘 B 버튼이 눌린 적이 있는가? 일 때 (득점!) 변수 점수의 값을 변수 슛의 값만큼 바꾸기 소리 GIGGLE 재생 + 마빗 화면에 점수 값 이동하며 보여주기

05동작 영상

※ 개인정보 보호를 위해 소리를 제거하고 일부 구간만 담은 영상입니다.

06제작 이야기

🏀 왜 자동 점수판인가

농구 챔피언스리그가 열리면 모두가 경기를 보고 싶어 합니다.
하지만 누군가는 점수판 앞을 지켜야 하죠.
이 팀은 "점수 올리느라 경기를 놓치는 사람"을 없애는 것을 목표로 삼았습니다.

⚙️ 버튼 두 개로 끝나는 운영

슛 순간 A 버튼으로 위치를 판정해 두고, 골이 들어가면 B 버튼만 누르면 끝.
소리와 함께 합산된 점수가 마이크로비트 화면에 흘러갑니다.
3점 라인 밖과 안에서 찍은 사진 104장으로 위치 판정 모델을 만들었습니다.
