🗣️ 음성인식 에어컨 컨트롤러

"더워!"라고 말하면 에어컨이 켜지고, "추워!"라고 말하면 꺼집니다.
음성 인식으로 제자리에서 바로 교실 온도를 조절하는 원격 제어 시스템입니다.

01왜 만들었나요?

🥵

문제 발견

수업이나 체육 활동 뒤에 덥거나 추운데, 교실 온도가 고정되어 있어 불편을 겪는 학생들이 많아요.

💡

해결 아이디어

"더워"라고 말만 하면 에어컨이 켜지게 하자!
수업에 방해받지 않고 제자리에서 바로 온도를 조절하는 거예요.

🌱

기대 효과

학생들의 의견이 즉시 반영되는, 학생에게 가장 직접적으로 도움이 되는 시스템입니다.

음성 명령 규칙

🥶 "추워 · 추운데 · 춥다" 신호 0 → 에어컨 OFF

이 팀은 이미지 분류 대신 음성 인식을 활용했습니다.
여섯 가지 표현 중 어떤 말이 들려도 알아듣도록, 단어마다 판별 블록을 하나씩 만들었습니다.

04핵심 코드

AI이거다 블록 코딩으로 작성한 실제 프로그램을 요약해 옮긴 것입니다.
인식된 문장 속에 특정 단어가 들어 있는지 검사해, 12번 핀의 디지털 신호로 모터를 켜고 끕니다.

메인 프로그램 — 음성 명령으로 에어컨 제어

🚩 프로그램이 실행될 때 음성 인식 언어를 한국어로 정하기 계속 반복하기 음성 인식 듣기 — 말이 끝날 때까지 기다리기 만약 인식 결과에 더워 가 있다면 마빗 12번 핀의 디지털 신호를 1로 정하기 (모터 ON) 만약 인식 결과에 추워 가 있다면 마빗 12번 핀의 디지털 신호를 0으로 정하기 (모터 OFF) … 더운데 덥다 추운데 춥다 도 같은 방식으로 판별

06제작 이야기

🗓 8차시의 기록

  1. 계획서 작성과 계획 세우기 (1~2차시)
  2. 에어컨 모형 제작과 코딩 (3차시)
  3. 음성 인식 적용 코딩 (4~5차시)
  4. 발표 자료 제작과 연습 (6~7차시)
  5. 보고서 마무리 (8차시)
