🤖 AI 로봇청소기

빗자루로는 해결이 어려운 교실 먼지!
레고로 만든 로봇청소기가 카메라로 더러운 곳을 감지해, 더러우면 물티슈 걸레로 왕복하며 닦고 깨끗하면 제자리로 돌아갑니다.

01왜 만들었나요?

🧹

문제 발견

교실에 먼지와 쓰레기가 너무 많아서, 쓰레받기와 빗자루만으로는 쉽게 해결하기 어려워요.

💡

해결 아이디어

카메라로 더러운 곳을 감지하는 로봇청소기를 만들어 더 빠르고 깨끗하게 해결하자!

🌱

기대 효과

청소가 빠르고 편해지고, 어디가 더럽고 깨끗한지도 정확하게 알 수 있습니다.

04핵심 코드

AI이거다 블록 코딩으로 작성한 실제 프로그램을 그대로 옮긴 것입니다.
팀이 가장 중요하게 꼽은 블록은 '분류 결과 요청하기' — 분류 결과가 없으면 로봇청소기는 아무 의미가 없어지기 때문입니다.

스위치 프로그램 — 버튼으로 청소 켜고 끄기

🔘 A 버튼이 눌린 적이 있는가? 일 때 변수 동작을 0으로 정하기 — 청소 멈춤 🔘 B 버튼이 눌린 적이 있는가? 일 때 변수 동작을 1로 정하기 — 청소 시작

메인 프로그램 — 더러움 감지와 걸레질

🚩 프로그램이 실행될 때 마빗 1번 핀을 서보모터 모드로 + 변수 동작 = 0 계속 반복하기 만약 1 = 동작 이라면 AI 모델의 분류 결과 요청하기 만약 분류 결과가 더러운 바닥 클래스라면 서보모터 0도 → 2초 → 180도 → 2초 (걸레질 왕복) 아니면 로봇청소기를 처음 위치로 되돌리기

05동작 영상

※ 개인정보 보호를 위해 소리를 제거하고 일부 구간만 담은 영상입니다.

06제작 이야기

🗓 8차시의 기록

  1. 역할 분담 · 브레인스토밍 (1차시)
  2. 레고로 로봇청소기 본체 제작 (2~3차시)
  3. 바닥 사진 촬영과 이미지 분류 학습 (4~5차시)
  4. 감지-걸레질 코딩 (6차시)
  5. 조립 마무리와 전체 점검 (7~8차시)

🔧 부딪히고, 해결하고

제작 중 로봇청소기가 갑자기 멈추거나 먹통이 되곤 했습니다.
연결을 여러 번 다시 시도한 끝에 움직이게 만들었습니다.

💬 팀원들의 한 마디

"로봇청소기 만들기가 굉장히 힘들고 어렵다는 걸 깨달았다", "외관을 만드는 게 쉬운 게 아니었다" — 시간이 더 있다면 앞뒤로만 움직이는 걸레질을 더 자유롭게 바꾸고 싶다고 합니다.
