🔍 분실물 분류 시스템

분실물을 카메라로 찍으면 AI가 펜·지우개·연필로 분류해 종류별 개수를 기록합니다.
찾으러 가기 전에 내 물건이 있을지 미리 확인할 수 있는 시스템입니다.

01왜 만들었나요?

🧦

문제 발견

분실물을 직접 찾으러 가야 해서 번거롭고, 가서 없으면 헛걸음에 스트레스를 받아요.

💡

해결 아이디어

분실물을 AI로 분류해 종류별 개수를 기록해 두면, 가기 전에 내 물건이 있을지 확인할 수 있어요!

🌱

기대 효과

분실물 보관 장소를 불필요하게 방문하는 일이 줄어듭니다.

04핵심 코드

AI이거다 블록 코딩으로 작성한 실제 프로그램을 요약해 옮긴 것입니다.
5초 카운트다운 → 판별 → 등록 → 조회로 이어지는 흐름을 변수 하나(판단)로 깔끔하게 연결했습니다.

메인 프로그램 — 분실물 촬영·등록·조회

🖱 촬영 버튼이 눌렸을 때 타이머 5부터 1초씩 카운트다운 표시하기 AI 모델의 분류 결과 요청하기 만약 펜의 신뢰도 ≥ 80% → 확인 텍스트 펜, 판단 = 0 혹은 지우개 ≥ 80% → 확인 텍스트 지우개, 판단 = 1 혹은 연필 ≥ 80% → 확인 텍스트 연필, 판단 = 2 아니면 → 화면에 오류 표시 (잘못된 등록 방지) ✅ 확인 버튼이 눌렸을 때 판단 값에 따라 펜·지우개·연필 개수를 +1 🔍 펜 · 지우개 · 연필 버튼이 눌렸을 때 해당 종류의 누적 개수를 화면에 표시하기

🔧 부딪히고, 해결하고

촬영 각도나 모양에 따라 펜·연필을 혼동하는 문제가 있었습니다.
사진을 충분히 학습시키고, 신뢰도 80%를 넘을 때만 결과를 인정하며, 못 넘으면 '오류'로 표시하는 3중 장치로 해결했습니다.
자료 수집도 인터넷 캡처에서 직접 촬영으로 바꾸며 더 좋은 데이터를 모았습니다.
