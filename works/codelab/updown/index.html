🔢 숫자 맞추기 — UP & DOWN

컴퓨터가 고른 1~100 사이의 숫자를 추리해 보세요.
UP·DOWN 힌트를 보고 범위를 좁히면 몇 번 만에 맞힐 수 있을까요?

updown.py — Python 3
숫자 입력:

💻 학생이 작성한 파이썬 코드

위 실행 화면은 아래 파이썬 코드를 웹 콘솔로 그대로 옮긴 것입니다.

import random

answer = random.randint(1, 100)   # 컴퓨터가 숫자를 고른다
count = 0

print("1부터 100 사이의 숫자를 맞혀 보세요!")

while True:
    guess = int(input("숫자 입력: "))
    count = count + 1
    if guess < answer:
        print("UP!")
    elif guess > answer:
        print("DOWN!")
    else:
        print(f"정답! {count}번 만에 맞혔어요!")
        break
🎲 random.randint

컴퓨터가 1~100 사이의 숫자를 무작위로 하나 고릅니다.
실행할 때마다 정답이 달라집니다.

🔁 while True + break

정답을 맞힐 때까지 계속 반복하다가, 맞히는 순간 break로 빠져나옵니다.

🔀 if / elif / else

입력한 수와 정답을 비교해 UP, DOWN, 정답 세 갈래로 나뉩니다.
