컴퓨터와 가위바위보 대결!
'그만'을 누를 때까지 전적이 쌓입니다. 과연 컴퓨터를 이길 수 있을까요?

rsp.py — Python 3

💻 학생이 작성한 파이썬 코드

위 실행 화면은 아래 파이썬 코드를 웹 콘솔로 그대로 옮긴 것입니다.

import random

print("가위바위보 게임! ('그만'을 입력하면 종료)")
win = 0
draw = 0
lose = 0

while True:
    me = input("나: ")
    if me == "그만":
        break
    com = random.choice(["가위", "바위", "보"])
    print(f"컴퓨터: {com}")
    if me == com:
        draw = draw + 1
        print("비겼다!")
    elif (me == "가위" and com == "보") or \
         (me == "바위" and com == "가위") or \
         (me == "보" and com == "바위"):
        win = win + 1
        print("이겼다!")
    else:
        lose = lose + 1
        print("졌다...")

print(f"전적: {win}승 {draw}무 {lose}패")
🎲 random.choice

리스트에서 하나를 무작위로 뽑습니다.
컴퓨터의 가위바위보가 여기서 결정됩니다.

🧮 and / or 조건 조합

"내가 이기는 세 가지 경우"를 or로 묶어 한 번에 판정합니다.

📊 변수로 전적 기록

win, draw, lose 세 변수에 결과를 쌓아 마지막에 전적을 발표합니다.
